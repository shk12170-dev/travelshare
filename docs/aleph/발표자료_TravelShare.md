# TravelShare 발표 자료

## 1. 서비스 소개

여행을 준비하는 사람은 코스와 최신 정보를 얻고, 여행을 다녀온 사람은 사진·영상·숏츠와 여행 로그로 추억을 공유하는 여행 커뮤니티입니다.

## 2. 해결하려는 문제

- 여행 정보와 여행 후 기록이 여러 서비스에 흩어져 있습니다.
- 코스 정보만 보거나 사진만 보는 사용자는 여행 흐름을 한 번에 파악하기 어렵습니다.
- 새 글, 댓글, 좋아요 소식을 놓치기 쉽습니다.

## 3. 주요 기능

- 동행·테마별 여행 코스와 지도
- 여행 로그 작성 및 사진 첨부
- 댓글·좋아요·팔로우·알림
- 사진·영상·숏츠 업로드와 유형별 보기
- 통합 검색과 반응형 화면

## 4. 시연 순서

1. 코스에서 지도와 여행 팁 확인
2. 로그 작성 및 사진 첨부
3. 다른 계정 팔로우 후 알림 확인
4. 댓글·좋아요 알림 확인
5. MP4 업로드 후 `영상 변환 중` → `영상 변환 최종 확인` 확인

## 5. 기술 구성

Next.js, React, Prisma, Better Auth, Turso, Vercel Blob, Vercel, Leaflet/OpenStreetMap을 사용했습니다.

## 6. 구현 과정에서 해결한 문제

알림 링크의 대상 정보가 누락되어 잘못된 페이지로 이동하던 문제와 영상 코덱 문자열 때문에 업로드가 거부되던 문제를 수정했습니다. 운영 사이트에서 두 흐름을 다시 확인했습니다.

## 7. 결과와 다음 계획

현재 핵심 기능은 배포 환경에서 사용할 수 있습니다. 이후에는 메일·푸시 알림, 소셜 로그인, 지도 좌표 정밀화, 영상 처리 고도화를 확장할 수 있습니다.
