# TravelShare 계획 설계서 (plan.md · v2 초안)

> v1(2026-09-30, AlephGate plan.md) 이후 실제 구현 결과를 반영한 새 버전입니다.
> 바꾼 이유: 자유 주제 과제로 직접 쓰고 싶은 여행 공유 앱(TravelShare)으로 주제를 확정했고 [확인: v1 내용과 비교해 한 줄로 고치세요],
> v1 당시 다른 AI가 "만들었다"고 한 파일이 실제로는 없어서 처음부터 다시 만들고 매 단계 실행으로 검증하는 방식으로 바꿨습니다.

## 1. 목표
동행 유형과 여행 테마로 코스를 찾고, 여행 기록과 사진·영상을 공유하는 반응형 웹앱.
핵심 기능: ① 동행·테마별 코스 추천 ② 여행 로그 작성·공유 ③ 사진·영상 게시

## 2. 작업 원칙
- 매 단계마다 **실행으로 검증**(빌드·코드 검사·자동 테스트·브라우저 확인)한 뒤 다음 단계로 진행
- 핵심 기능 3가지를 먼저 완성하고, 부가 기능은 그다음
- 비밀값(키·비밀번호)은 저장소에 올리지 않음
- 무료 범위에서 운영 (과제 제출용·비상업)

## 3. 기술 구성
| 영역 | 선택 | 이유 |
|---|---|---|
| 화면·서버 | Next.js 16 (App Router), React 19, Tailwind CSS 4 | 한 프로젝트에서 화면과 서버 처리를 함께 만들 수 있음 |
| DB | 개발: SQLite 파일 / 배포: Turso (Prisma 7 + libSQL) | 같은 코드로 개발과 배포를 모두 처리, 무료 5GB·정지 없음 |
| 파일 저장 | 개발: PC 폴더 / 배포: Vercel Blob | 결제 수단 없이 무료 1GB, 브라우저가 직접 업로드 (R2로 교체 가능) |
| 로그인 | Better Auth (이메일·비밀번호, 소셜 로그인 확장 가능) | 직접 구현보다 안전한 검증된 라이브러리 |
| 배포 | Vercel 무료(Hobby) | 비상업 용도 허용, GitHub 연동 자동 배포 |
| 테스트 | Vitest(단위), Playwright + axe(브라우저·접근성) | 기능과 보안 동작을 자동으로 반복 확인 |

## 5. 변경 이력
- **Next.js 14 → 16으로 되돌림**: 이전 AI 작업에서 14로 낮췄으나 설정 파일이 모두 16 기준이고 14.0.4에 보안 취약점이 있어 되돌림
- **배포 구조 변경 (서버 한 대 → Vercel + Turso + R2)**: 무료 운영 조건에 맞추기 위해. 그에 따라 업로드를 "브라우저가 저장소에 직접 올리는" 방식으로, 횟수 제한 기록을 DB로 옮김
- **사진 저장소 R2 → Vercel Blob**: R2는 무료라도 결제 수단 등록이 필요해, 등록 없이 쓸 수 있는 Vercel Blob으로 변경(영상 한도 20MB)
- **Supabase 검토 후 Turso 유지**: Supabase 무료는 1주일 미접속 시 일시정지 → 평가 기간에 사이트가 멈출 위험
- **부가 기능 추가**: 핵심 기능 사용성을 위해 댓글·좋아요·검색 등을 추가 (지도·팔로우 등은 다음 버전)
- **[v3] 로그 사진 첨부**: 글과 사진을 따로 올리던 불편을 줄이려고 로그에 사진을 직접 붙이게 함. 저장 전 사진은 "임시" 상태로 두어 목록·검색에 나오지 않게 함
- **[v3] 코스 지도**: 방문 순서를 한눈에 보도록 지도 추가. 키가 필요 없는 OpenStreetMap + Leaflet 선택, 좌표는 대략적인 위치로 안내
- **[v3] 계정 삭제·이용 안내**: 개인정보 처리 내용과 삭제 방법을 화면으로 제공
- **[최종] 샘플 미디어 표시**: 사용자 후기에서 "사진이 표시되지 않는다"는 지적이 있어, 실제 파일 없는 샘플 항목에 "샘플 이미지" 표시를 달아 오해를 없앰
- **[최종] 팔로우**: 선택 기능 중 팔로우·알림을 검토해 팔로우만 구현(알림은 메일·푸시 서비스가 필요해 제외). 영상 화질 변환은 무료 서버에서 처리하기 어려워 제외
- **[최종] 휴대폰 점검**: 7개 화면에서 가로 넘침이 없음을 확인하고, 누르기 작은 버튼(사진 빼기·좋아요·팔로우 등)을 키움
- **[v3] 우선순위 조정**: 사용자 피드백 수집은 제한적이라 기능 완성도·안전 항목을 먼저 진행
