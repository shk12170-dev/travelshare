# 최종 제출 자료 — TravelShare

> 최종 제출 양식에 맞춰 칸별로 붙여 넣을 수 있게 정리한 자료입니다. 체험 계정 비밀번호와 "내가 판단한 일"은 제출 전 직접 확인하세요.

## 한 줄 소개
혼자·친구·연인·가족 여행 코스를 추천받고, 여행 기록과 사진·영상을 서로 공유하는 웹앱입니다.
- 결과물: https://travelshare-shk.vercel.app
- 소스: https://github.com/shk12170-dev/travelshare

## 만든 기능 (모두 실제 배포 주소에서 동작)
| 구분 | 기능 |
|---|---|
| 코스 추천 | 동행(혼자·친구·연인·가족)·테마(자연·도시·맛집·문화) 필터, 코스 순서·팁, **코스 지도(번호 마커·경로)** |
| 여행 로그 | 작성·수정·삭제, **사진 5장까지 첨부**, 댓글·좋아요, **팔로우와 팔로잉 탭** |
| 사진·영상 | 사진·영상·숏츠 업로드와 분류 보기, 브라우저에서 사진 축소·위치 정보 제거, 위조 파일 차단 |
| 계정 | 이메일 가입·로그인, 프로필 수정, **계정 삭제**, 비밀번호 변경·재설정 |
| 안내 | **이용 안내·개인정보 화면**, 데모 사이트 안내 띠, 샘플 데이터 "샘플 이미지" 표시 |
| 공통 | 통합 검색, 휴대폰 화면 대응, 접근성 검사 통과 |

## 확인하는 방법 · 3단계
1. 결과물 주소의 **코스**에서 코스를 열어 지도의 번호 순서를 확인합니다.
2. 체험 계정(seacat@sample.travelshare.test / 비밀번호: [직접 입력])으로 로그인해 **로그 쓰기**에서 사진을 첨부해 글을 올립니다.
3. 다른 사람의 로그 상세에서 **팔로우**를 누르고, **로그 → 팔로잉** 탭에서 그 사람의 글이 모이는지 확인합니다.

| 2차 | 로그 사진 첨부, 코스 지도, 계정 삭제, 이용 안내·개인정보 화면, 사용자 후기 2명 확인 |

## 사용자 후기와 반영
- A군: "코스·기록을 보는 재미가 있고 미디어 구분이 편함. 일부 사진이 표시되지 않음" → 샘플 항목에 "샘플 이미지" 표시 추가
- B양: "코스 순서가 지도에 보여 동선 파악이 편함, 테마 필터와 기록 남기기도 좋음" → 지도·필터 유지, 기록 기능 보완(사진 첨부·팔로우)

## 품질과 안전
- 자동 테스트 138개 통과(단위 94 + 브라우저 44, 접근성 검사 포함)
- 본인 글만 수정·삭제, 업로드 파일 내용 검사, 로그인·작성·좋아요 횟수 제한
- 운영 DB 변경 전 백업, 비밀번호·키는 저장소에 올리지 않음

## 구성 (모두 무료 플랜)
Vercel(앱) + Turso(DB) + Vercel Blob(사진·영상), Next.js 16 · React 19 · Prisma · Better Auth · Leaflet(OpenStreetMap)

## 알려진 한계와 다음 계획
- 알림(메일·푸시)과 비밀번호 재설정 메일은 메일 발송 서비스를 연결해야 해 제외했습니다.
- 영상은 20MB까지, 화질 변환은 무료 서버에서 처리하기 어려워 제외했습니다.
- 구글·카카오 로그인은 버튼과 구조만 있고 키 연결은 하지 않았습니다.
- 지도 좌표는 대략적인 위치입니다.
