# 중간 점검 2차 — 제출 양식 (칸별로 그대로 붙여 넣기)

## 이번에 만든 것
1차 점검 뒤 사용자가 직접 쓸 때 부족했던 부분 4가지를 만들어 같은 주소에 반영했습니다.

1. **여행 로그에 사진 첨부** — 로그를 쓰거나 고칠 때 사진을 최대 5장 붙일 수 있습니다. 로그 상세에 "첨부한 사진" 갤러리가 나오고, 로그 목록 카드에는 대표 사진이 보입니다. 쓰다가 저장하지 않고 떠난 사진은 어디에도 나오지 않으며 24시간 뒤 정리됩니다. 남의 사진을 내 로그에 붙이려는 시도는 서버가 막습니다.
2. **코스 지도** — 코스 상세 화면에 방문 순서대로 번호 마커와 점선 경로를 보여 주는 지도(OpenStreetMap)를 넣었습니다. 샘플 코스 6개 18곳에 좌표를 넣었고, 출처 표기와 "대략적인 위치" 안내를 함께 보여 줍니다.
3. **계정 삭제** — 프로필 수정 화면에서 비밀번호를 확인하고 내 계정과 올린 글·사진·댓글·좋아요를 한 번에 지울 수 있습니다. 평가용 샘플 계정은 보호됩니다.
4. **이용 안내·개인정보 화면(/privacy)** — 어떤 정보를 어디에 쓰는지, 저장 위치(Vercel·Turso·Vercel Blob), 삭제 방법을 쉬운 말로 정리했습니다. 모든 화면 위에 "실제 개인정보를 입력하지 마세요" 안내 띠도 있습니다.

그 밖에 샘플 데이터를 다시 넣어도 사용자가 누른 좋아요 수가 초기화되지 않게 고쳤습니다.
자동 테스트는 단위 94개 + 브라우저 41개(접근성 검사 포함), 총 135개를 모두 통과했습니다(1차는 121개).

## 확인하는 방법 · 3단계 이내
1. 결과물 주소의 **코스** 탭에서 "제주 동쪽 해안 드라이브"를 열어 번호 마커와 경로가 있는 **코스 지도**를 확인합니다.
2. 체험 계정으로 **로그인**하고 **로그** 탭의 "+ 로그 쓰기"에서 제목·본문과 함께 "사진 추가"로 사진을 붙여 작성하면, 상세 화면에 "첨부한 사진"이 나옵니다.
3. 화면 맨 위의 "이용 안내"에서 개인정보 처리 내용을 보고, **프로필 → 수정** 맨 아래에서 계정 삭제 절차(비밀번호 확인)를 확인합니다. (실제로 지우려면 회원가입으로 만든 새 계정을 쓰세요.)

## 바뀐 점과 그 이유
- **사진은 "임시 상태"로 먼저 올림**: 로그 글을 저장하기 전에도 사진을 올릴 수 있게 하되, 저장 전 사진은 목록·검색·통계에 나오지 않도록 별도 상태로 두었습니다. 글 저장 때 내 사진인지 서버가 다시 확인해 붙입니다.
- **지도는 무료·키 없는 OpenStreetMap + Leaflet 선택**: 카카오·구글 지도는 키 발급과 사용 조건이 필요해 과제 취지(무료·비상업)에 맞지 않았고, OSM은 출처만 표기하면 소규모 사이트에서 쓸 수 있습니다. 위치가 정확한 주소가 아니라 대략적인 좌표라서 화면에 그렇게 안내합니다.
- **사용자 피드백 항목은 제한적으로 진행**: 평가 기간 안에 많은 사용자를 모으기 어려워, 기능 완성도와 안전(개인정보·삭제·접근성)을 먼저 채우는 쪽으로 우선순위를 바꿨습니다.
- **DB 변경은 백업 후 적용**: 로그 사진과 지도 좌표를 위해 DB 구조를 두 번 바꿨고, 운영 DB는 백업 파일을 만든 뒤 데이터를 보존하는 방식으로 적용했습니다.
- **오류 수정**: 접근성 검사에서 지도 영역의 역할 지정이 문제로 잡혀 제거했습니다. 시드 재실행이 좋아요 수를 덮어쓰던 문제도 고쳤습니다.

## AI에게 맡긴 일과 내가 판단한 일
**AI에게 맡긴 일**
- 사진 첨부·지도·계정 삭제·개인정보 화면의 코드와 DB 변경 작성
- 자동 테스트 작성·실행, 오류 원인 분석과 수정
- 지도 서비스 사용 조건(OSM 타일 정책) 조사, 장소별 대략적 좌표 입력
- 운영 DB 백업·적용과 배포 후 화면 확인

**내가 직접 판단·수행한 일**
- 2차 우선순위 결정: 로그 사진 첨부 → 코스 지도 순서로 진행하고, 사용자 피드백 수집은 제한적이라 제외하기로 판단
- 개인정보 화면의 "이용 방식"·"제3자" 표현이 어색한 것을 직접 찾아 수정 지시, 계정 삭제 기능과 GitHub 이슈로 삭제를 요청하는 방식 결정
- 운영 사이트에서 직접 사진을 올려 보며 동작을 확인하고, 확인 결과를 바탕으로 다음 작업 지시
- 결제 수단을 등록하지 않는 무료 운영 원칙 유지
- 1차 점검 제출과 Vercel·Turso 계정·환경 변수 관리 직접 수행
