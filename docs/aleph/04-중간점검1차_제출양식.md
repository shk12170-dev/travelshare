# 중간 점검 1차 — 제출 양식 (칸별로 그대로 붙여 넣기)

## 이번에 만든 것
여행 커뮤니티 웹앱 **TravelShare**를 만들어 인터넷에 공개했습니다. 핵심 기능 3가지를 모두 실제로 동작하게 구현했습니다.

1. **동행·테마별 코스 추천** — 혼자·친구·연인·가족 × 자연·도시·맛집·문화로 코스를 걸러 보고, 코스별 방문 순서와 팁, 그 코스를 다녀온 사람들의 로그를 볼 수 있습니다.
2. **여행 로그 작성·공유** — 로그인한 사용자가 여행 기록과 팁을 쓰고 수정·삭제할 수 있고, 댓글과 좋아요로 소통합니다. 본인 글만 수정·삭제할 수 있습니다.
3. **사진·영상 게시** — 사진·영상·숏츠를 올리고 유형별로 모아 봅니다. 큰 사진은 올리기 전에 브라우저에서 자동으로 줄이고 위치 정보를 지웁니다. 위조 파일과 크기 초과는 서버가 거부합니다.

그 밖에 이메일 회원가입·로그인, 통합 검색, 프로필 수정, 휴대폰 화면 대응을 갖췄고 자동 테스트 121개(단위 88·브라우저 33, 접근성 검사 포함)를 모두 통과했습니다.
배포 구조는 Vercel(앱) + Turso(DB) + Vercel Blob(사진·영상)으로, 모두 무료 플랜입니다.

## 확인하는 방법 · 3단계 이내
1. 결과물 주소에 접속해 **코스** 탭에서 "가족"과 "자연"을 눌러 조건에 맞는 코스만 나오는지 확인합니다.
2. 아래 체험 계정으로 **로그인**한 뒤 **로그** 탭의 "+ 로그 쓰기"로 글을 작성하면 상세 화면으로 이동하고, 내 글에만 "수정·삭제" 버튼이 보이는 것을 확인합니다.
3. **미디어** 탭에서 "파일 선택" → 설명·지역 입력 → "게시하기"로 사진을 올리면 목록 맨 앞에 나타납니다.

체험 계정: seacat@sample.travelshare.test / 비밀번호: [제출 메모에 직접 입력]
(회원가입으로 새 계정을 만들어도 모든 기능을 확인할 수 있습니다.)

## 바뀐 점과 그 이유
- **개발 방식 변경**: 이전 AI 작업이 "만들었다"고 한 파일이 실제로는 없었습니다. 그래서 처음부터 다시 만들고, 매 단계 빌드·자동 테스트·브라우저 확인으로 검증한 뒤 다음 단계로 넘어갔습니다.
- **버전 유지**: 이전 작업이 낮춰 둔 Next.js 14 대신 설정과 맞는 최신 16을 유지했습니다(14.0.4에 알려진 보안 취약점이 있고 설정 파일이 모두 16 기준).
- **배포 구조 변경**: 서버 한 대에 파일을 저장하던 구조에서, 무료로 오래 켜 둘 수 있는 Vercel + Turso + Vercel Blob 구조로 바꿨습니다. 업로드도 "서버가 받는" 방식에서 "브라우저가 저장소에 직접 올리는" 방식으로 바꿨습니다.
- **저장소 선택**: Cloudflare R2는 무료여도 결제 수단 등록이 필요해, 등록 없이 쓸 수 있는 Vercel Blob으로 바꿨습니다(영상 한도는 20MB로 낮춤).
- **DB 선택**: Supabase는 1주일 접속이 없으면 일시정지돼 평가 기간 중 사이트가 멈출 수 있어, 정지가 없는 Turso를 유지했습니다.
- **안내 문구 정직하게 수정**: 메일 발송을 연결하지 않았는데 "메일을 보냈습니다"라고 나오던 비밀번호 찾기 화면을, 실제 상태를 알리는 안내로 바꿨습니다.

## AI에게 맡긴 일과 내가 판단한 일
**AI에게 맡긴 일**
- 화면·서버·DB 코드 작성, 자동 테스트 작성과 실행
- 오류 원인 분석과 수정(예: 배포 빌드 실패, 500 오류)
- 라이브러리와 호스팅 서비스의 공식 문서 조사, 비용·조건 비교표
- 보안 점검(위조 파일 업로드, 비밀번호 대입 시도, 외부 주소로 빼돌리기 등)과 보완 코드

**내가 직접 판단·수행한 일**
- 주제(여행 코스·기록·사진 공유)와 핵심 기능 3가지, 추가 기능 범위 결정
- 이전 AI 작업을 그대로 믿지 않고 실제 파일 기준으로 다시 점검하도록 지시
- 사용자 증가 대비 개선은 먼저 하고 큰 구조 변경은 나중에 하기로 결정
- 호스팅 후보(유료 Fly.io, 자체 PC, 무료 조합, Supabase)를 비교해 과제 취지(비상업·무료)에 맞는 구성 선택
- 결제 수단을 등록하지 않기로 결정해 R2 대신 Vercel Blob 채택
- Turso·Vercel·GitHub 계정 가입과 키 발급, 노출된 Cloudflare 키 폐기, 환경 변수 직접 입력
- 배포 결과와 오류 화면을 확인하고 AI에게 전달해 수정을 이어 감
