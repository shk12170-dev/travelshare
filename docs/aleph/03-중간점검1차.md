## 이번에 만든 것
여행 커뮤니티 웹앱 TravelShare의 핵심 기능 3가지를 모두 구현했습니다.
- 동행 유형·테마로 거르는 **코스 추천**과 코스 상세(방문 순서·팁)
- **여행 로그** 작성·수정·삭제, 댓글·좋아요
- **사진·영상(숏츠) 게시**와 유형별 보기 (큰 사진은 자동으로 줄이고 위치 정보 제거)
- 이메일 회원가입·로그인, 본인 글만 수정·삭제하는 권한, 통합 검색, 휴대폰 화면 대응
- 자동 테스트 121개(단위 88 · 브라우저 33, 접근성 검사 포함) 통과
- Vercel + Turso(DB, 도쿄) + Vercel Blob(사진·영상)으로 무료 배포

## 확인하는 방법 (3단계)
1. 결과물 URL에 접속해 **코스** 탭에서 "가족"·"자연"을 골라 코스를 확인
2. **회원가입** 후 **로그** 탭 → "+ 로그 쓰기"로 여행 기록 작성
3. **미디어** 탭에서 사진을 올리고 목록에 나타나는지 확인

## 바뀐 점과 그 이유
- 이전 AI가 만들었다고 한 파일이 실제로 없어서 처음부터 다시 만들고, 매 단계 실행으로 검증하는 방식으로 바꿨습니다.
- 무료로 공개하기 위해 서버 한 대 구조에서 Vercel + Turso + Vercel Blob 구조로 바꿨습니다.
- 사용자가 늘어날 때를 대비해 목록 페이지 나누기, 업로드 방식 개선, 글쓰기·로그인 횟수 제한을 넣었습니다.

## AI에게 맡긴 일과 내가 판단한 일
**AI에게 맡긴 일**
- 코드 작성, 자동 테스트 작성과 실행, 오류 원인 찾기와 수정
- 라이브러리·호스팅 서비스의 공식 문서 조사와 비교표 작성
- 보안 점검(위조 파일 업로드, 비밀번호 대입, 외부 주소로 빼돌리기 등)

**내가 판단한 일** [확인: 본인 기억과 맞게 고치세요]
- 이전 AI 작업 결과를 그대로 믿지 않고 실제 파일 기준으로 다시 점검하게 함
- Next.js 버전을 낮춘 이전 판단을 검토받고, 최신 버전 유지로 결정
- 추가 기능 범위 결정(댓글·좋아요·검색·비밀번호 재설정 등)
- 사용자 증가 대비 개선은 먼저 하고, 큰 구조 변경은 필요할 때 하기로 결정
- 호스팅을 유료(Fly.io)·자체 PC·무료 조합 중 비교한 뒤 무료(Vercel + Turso + Vercel Blob)로 결정, R2는 결제 수단 등록이 필요해 Vercel Blob으로 변경
- Supabase를 검토했으나 과제 평가 기간의 일시정지 위험 때문에 Turso 유지
