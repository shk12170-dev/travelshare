# TravelShare 여행 앱 과제 제출 자료

## 이번에 만든 것

TravelShare는 여행을 계획하는 사람에게 코스와 최신 여행 정보를 제공하고, 여행을 다녀온 사람은 여행 로그·사진·영상·숏츠를 공유해 추억을 남길 수 있는 여행 커뮤니티 웹앱입니다.

- 여행 코스 추천: 동행 유형·테마 필터, 코스 순서·팁·지도
- 여행 로그: 작성·수정·삭제, 사진 첨부, 댓글·좋아요
- 소셜 기능: 팔로우·팔로잉, 팔로우·댓글·좋아요·새 로그 알림
- 미디어: 사진·영상·숏츠 업로드, 미디어 유형별 보기
- 영상 처리: 업로드 중 브라우저 영상 변환 후 저장 및 변환 결과 표시
- 계정: 이메일 가입·로그인, 프로필 수정, 비밀번호 변경·재설정, 계정 삭제
- 공통: 통합 검색, 반응형 화면, 이용 안내·개인정보 화면, 접근성·오류·로딩 처리

## 확인하는 방법 (3단계 이내)

1. [TravelShare 배포 사이트](https://travelshare-shk.vercel.app)에 접속해 코스 메뉴에서 코스와 지도 동선을 확인합니다.
2. 가입 또는 체험 계정으로 로그인한 뒤 로그를 작성하고 사진을 첨부합니다. 다른 계정에서 해당 작성자를 팔로우하면 알림 메뉴에서 팔로우·새 로그 알림을 확인할 수 있습니다.
3. 미디어 메뉴에서 영상을 업로드합니다. 업로드 중 `영상 변환 중`, 완료 후 `영상 변환 최종 확인`과 영상 항목이 표시되는지 확인합니다.

## 바뀐 점과 그 이유

- 알림에 작성자·대상 로그 정보가 빠져 잘못된 주소로 이동하던 문제를 수정했습니다. 알림 클릭 시 작성자 로그 또는 댓글·좋아요가 발생한 로그로 정확히 이동합니다.
- 새 여행 로그 알림이 알림 작성자의 로그 목록으로 이동하도록 수정했습니다.
- 알림 안내 문구를 팔로우뿐 아니라 댓글·좋아요·새 로그까지 포함하도록 수정했습니다.
- 영상 변환 결과의 MIME 타입을 `video/webm`으로 정규화하고 확장자·코덱 문자열이 포함된 업로드도 안전하게 처리하도록 수정했습니다.
- 실제 영상 파일로 운영 사이트 업로드를 재검증해 변환 완료 표시까지 확인했습니다.

## AI에게 맡긴 일과 내가 판단한 일

### AI에게 맡긴 일

- 화면·서버·DB 기능 구현과 기능 간 연결
- 알림·팔로우·댓글·좋아요·미디어 업로드 로직 구현
- 영상 MIME 오류 원인 분석과 변환 업로드 보완
- 테스트·린트·서비스 연결 점검, 배포 후 동작 확인
- 제출 문서와 작업 기록 정리

### 내가 판단한 일

- 여행 정보와 여행 추억을 한 서비스에서 연결하는 주제와 핵심 기능 결정
- 무료 운영을 기준으로 Vercel·Turso·Vercel Blob을 사용하는 배포 구조 선택
- 실제 사용자 흐름(팔로우, 알림, 로그 작성, 영상 업로드)을 최종 검증할 시나리오 결정
- 개인정보·계정 삭제·업로드 파일 처리 범위와 서비스 문구 검토
